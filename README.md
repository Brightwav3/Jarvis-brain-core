# Jarvis Brain Core

Infrastructure repository for the first, model-independent foundation of the long-term Jarvis system.

Phase 0 defines only a headless Jarvis Core runtime: lifecycle, configuration, structured logging, an event bus, component registry, local API, health reporting, and automated tests. It intentionally excludes AI, voice, devices, automation, and memory.

The complete scope and delivery rules are in [workplan.md](workplan.md).
